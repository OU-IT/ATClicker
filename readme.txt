简介
这是一个自动点击的小程序，匹配模板点击
1. 组合点击（优先）
条件：
icon2.png 与 icon3.png 都成功加载；
当前帧中两个模板同时命中（匹配分数 ≥ 当前阈值）；
距离上次点击已超过 TAP_COOLDOWN（默认 0.8 秒）。
动作：
点击 icon2 的中心坐标；
等待 COMBO_CLICK_DELAY（默认 0.3 秒）；
点击 icon3 的中心坐标；
tap_count += 2，更新 last_tap_time 和 last_pos = icon3 位置；
本次不再执行单图标逻辑。
2. 单图标点击（组合未命中时）
条件：
当前帧中 icon.png 命中；
距离上次点击已超过 TAP_COOLDOWN。


用法
1、打开手机的开发者模式，打开ADB调试(网上一堆教程)
2、打开看课的软件，打开1.5倍速横屏播放
3、然后连接数据线，插到电脑上，运行主程序
4、看到程序上有显示画面，挂机就可以了



常用快捷键
画面窗口获得焦点时（用鼠标点一下画面窗口），可以按：

按键	作用
Q	退出程序
S	保存当前画面为图片，方便你检查哪里没匹配上
T	强制点击屏幕正中心（测试用）
+ 或 =	调高匹配要求（更严格）
-	调低匹配要求（更宽松）
